
#Proyecto Final / Calculadora De Matrices / JAVA

En este proyecto crearemos una Calculadora de Matrices que se desarrollara en Java que permitira realizar operaciones de calulo diferencial  e integrar funciones ingresadas por el usuario.

el programa permitira ingresar expreciones matematicas, seleccionar la variable a trabajar y calcular las derivadas, integrales indefinidas e integrales definidas.

- Este proyecto  se realizo por los estudiantes del cuarto ciclo de la carrear de Ingenieria en sistemas, de la Universidasd Mariano Galvez, Solola.

#Objetivos 

Desarrollar una aplicacion que facilite los calcular de operaciones de derivadasy integrales en donde veremos la Herencia, Manejo de execpciones etc.
